03 / INPUT CONTRACT

06 / CANVAS PLACEMENT

每做好一张，就马上排列一张

画布不是最终收尾工作，而是每个任务完成时的即时事务。日期决定横向分区，同一天的 SKC 只能纵向堆叠；每个 SKC 再按四视角分行。

横向 X 轴 · 日期从左到右，并为完整 10 槽宽度预留空间 →
8月13日DATE REGION 01
SKC A正面 ↓ 侧面 ↓ 背面 ↓ 全身
SKC B位于同日上一 SKC 的下方
8月14日PREVIOUS RIGHT EDGE + GAP
SKC C新日期整体放在前一天右侧
SKC D同日继续向下，不左右并排

定位键：日期 → SKC → 视角 → 动作/尝试。图片等宽且保持原始比例；行内水平间距约为图片宽度的 8%，视角行间距约为图片高度的 8%，SKC 区块间距约为图片高度的 25%。新日期从前一日期的实际最右边界加安全间距开始。

连续等宽 10 格 · 前 5 主槽 · 后 5 同视角补图槽
01 · 结果完成暂停补位提交
02 · 放入主槽按视角与动作定位
03 · 视觉确认尺寸、间距、保存状态
04 · 再补队列填充释放的并发位
07 / QUALITY GATE

生成只是候选，核验通过才算完成

20 张基础图生成完后进行统一质检。每个视角最多生成10张：5张基础图加最多5张补图；达到5张合格图或10张总量时立即停止该视角。

CANONICAL IDENTITY身份只认正面/1.jpg

它是唯一身份真源；侧面、背面和全身参考只控制姿势、身体方向、裁切与构图。身份漂移以 identity-drift 拒绝。

PARTIAL / HEADLESS SOURCE源图缺头，也要完成身份

源图只露部分头部或完全无头时，依据可见肤色、发型、年龄感、颈肩与体态证据自然补全，不凭空更换模特。

HEAD CROP FLOOR正面 / 侧面 / 背面至少半个头部

最终画面最少保留半个头部；完整头部允许。低于边界时按 head-crop-below-minimum 拒绝。

COMPLETE FULL BODY全身图必须从头顶到鞋底完整

完整发冠、脸、身体、服装、双脚与鞋底连续入镜，并在头顶和鞋底外留出安全边距。

CONDITIONAL DRESS FRAME确认膝下连衣裙才锁定完整裙摆

从肩部/领口连续展示至完整裙摆最低点，裙摆下方保留可见安全边距，不接触边缘、不遮蔽主要轮廓、不改变视觉长度；任一违反以 long-dress-hem-cropped 拒绝。

NEGATIVE PROMPT CONTRACTNegative Prompt 脚本生成且不可编辑

render_negative_prompt 根据视角、身份、裙长与鞋履合同生成唯一字符串；Markdown 只说明调用方式，不能改写、重排或追加缺陷词。

date-skc-four-row-v3日期 → SKC → 四视角 → 主图 / 补图

日期横向排列，同日 SKC 纵向堆叠；每个 SKC 固定正面、侧面、背面、全身四行，每行先 5 个主槽再 5 个补图槽。

产品一致性
  • 颜色、版型、领口、袖型、长度和面料正确
  • 视角与动作合同一致
  • 包袋、鞋子和手部正确
图像真实性
  • 单图、单个成年模特、无拼图
  • 光向、投影、反射与色温统一
  • 无抠图白边、严重肢体错误、文字或水印
四视角不得混淆

正面、侧面、背面、全身分别服务于不同展示目的，不能仅凭动作名称代替真实视角核验。

全身图专属边界

从头发最高点到两只脚底连续完整入镜，完整脸部、两只鞋、脚趾与鞋底可见，头顶和脚下均留安全边距。

BASE · 5每个动作先生成1张基础候选
CORRECTION · ≤5优先让每个失败动作获得一次补图
VIEW CAP · 10不足5张合格则 blocked:quality-cap
08 / RESUME

任何中断，都从 run-state 继续

每次可观察状态变化和每次画布移动都会落盘。重新运行时先查 Lovart 中已有标签，避免重复提交。

qualified

直接跳过，不重新生成

submitted / queued

先在月度项目中查找可见任务标签

rejected

当前视角累计未满 10 张时，按补图顺序继续带证据纠错

blocked

只隔离当前动作、视角或 SKC；批次继续

canvas_placement

记录行号、主槽/补图位和视觉确认结果
