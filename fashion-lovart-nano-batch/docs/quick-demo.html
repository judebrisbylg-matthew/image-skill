Fashion Lovart Nano Batch

线稿辅助试衣流程不变，最终 Prompt 专门适配 Nano Banana Pro

这个 skill 用于服装电商白底穿搭图。前面仍按“对标图转黑白线稿、提取人物外观锁、产品拆解、策略确认”执行；只有最后一步输出 Nano Banana Pro 更容易控制的结构化英文 Prompt。

黑白线稿 人物外观锁 产品不混图 最终 3:4 4K output 纯白 #FFFFFF
适用场景

多参考图服装试穿，最终在 Nano Banana Pro 生成白底电商图。

核心变化

不改前置流程，只改最终白底穿搭展示图 Prompt 的写法。

默认规格

3:4 ratio，4K output，pure white #FFFFFF background。

调用方式

$fashion-lovart-nano-batch + 图号角色说明 + 执行流程

一、输入图片怎么分类

每类图只负责自己的部分，避免 Nano Banana Pro 把多张图混成 moodboard。

PRODUCT SOURCE

产品图

只控制最终服装：品类、颜色、版型、领口、袖型、面料、印花、缝线、下摆和真实体量。

BENCHMARK SOURCE

对标图

先用于生成黑白线稿，同时提取人物外观锁。它不直接控制最终服装设计。

LINE_ART SOURCE

确认后的黑白线稿

只控制姿势、构图、裁切、身体比例、手脚位置、拍摄距离和兼容穿着行为。

MODEL APPEARANCE LOCK

人物外观锁

从对标图提取，用来锁肤色一致性、发色、发型和基础可见人物外观。

ACCESSORY SOURCES

配饰图

只控制明确提供的项链、耳环、手链、包、鞋等配饰。没有提供就不生成。

BOTTOMS SOURCE

下装图

当产品是上衣时，下装图只控制牛仔裤、长裤、半裙等下装，不参与上衣设计。

二、完整执行流程

0

参考图角色映射

确认哪些图是产品图、对标图、配饰图、下装图。用户图号明确时可直接进入下一步。

输入整理
1

确认黑白线稿生成策略

分析对标图要保留的姿势、比例、裁切、手位、腿位、穿着空间关系，并提取人物外观锁。

需要确认
2

生成黑白线稿 Prompt

输出中英文线稿 Prompt，用 image generation 把对标图转为黑白线稿参考。

生成线稿
3

确认线稿可用

用户确认或上传线稿后，才能继续产品特征拆解。线稿只用于最终图的姿势和空间关系。

需要确认
4

产品特征拆解

只看产品图，拆解品类、颜色、版型、领口、袖型、下摆、面料和必须保留细节。

需要确认
5

最终白底展示图策略

确认每个来源的控制范围、防混图规则、动作硬锁、肤色来源、配饰可见性和输出规格。

需要确认
6

输出 Nano Banana Pro Prompt

最终 Prompt 用短块结构，先写角色合同和优先级，再写服装、姿势、外观、配饰和禁止项。

最终产物

三、三个必须停下来确认的节点

Gate 1：线稿策略确认

没确认黑白线稿策略和人物外观锁之前，不生成线稿 Prompt。

Gate 2：线稿可用确认

没确认或上传可用线稿之前，不进入产品拆解。

Gate 3：最终策略确认

没确认产品拆解和最终展示图策略之前，不输出最终 Nano Banana Pro Prompt。

四、推荐调用方式

直接这样说：

[$fashion-lovart-nano-batch] 图1-图4是产品图；图5-图8是配饰图；图9是对标图。执行流程

如果某张“配饰图”其实是牛仔裤、裙子或裤子，执行中会把它归入 BOTTOMS SOURCE，避免下装被当作配饰处理。

五、常见错误说法

“参考这些图帮我生成一张好看的穿搭图。” 这个说法太宽，会让模型混合产品、对标图、肤色、配饰和背景。
“直接出最终 Prompt。” 这会跳过黑白线稿和人物外观锁，不符合这个 skill 的流程。

六、最终 Prompt 的分类结构

区块 作用 重点
FINAL OUTPUT 定义最终图规格 3:4 ratio，4K output，pure white #FFFFFF background，一张单图。
REFERENCE ROLE CONTRACT 明确每类参考图职责 产品只控服装，线稿只控姿势，外观锁只控肤色发型，配饰/下装只控各自物件。
REFERENCE PRIORITY 解决冲突时的优先级 产品细节优先产品图；动作构图优先线稿；肤色发型优先外观锁。
GARMENT HARD LOCK 锁定产品身份 写清品类、颜色、领口、袖型、面料、长度、下摆、缝线和禁止改款。
POSE AND BODY HARD LOCK 锁定动作构图 写清裁切、身体比例、手位、腿位、包位、身体角度和画面尺度。
MODEL APPEARANCE HARD LOCK 锁定人物外观 肤色一致性、发色、发型、基础模特外观；不从黑白线稿推断肤色。
ACCESSORIES AND BOTTOMS 迁移搭配物件 逐一写明配饰/下装的类别、数量、材质、位置和可见性。
DO NOT INCLUDE 防止混图和乱生成 禁止文字、水印、原对标服装、线稿残留服装设计、人台、额外造型、改姿势和改裁切。

七、最终 Prompt 示例骨架

实际执行时会把方括号内容替换成当前图片的具体产品和搭配细节。

FINAL OUTPUT
Create one high-end fashion ecommerce studio photo, 3:4 ratio, 4K output, pure white #FFFFFF background.

REFERENCE ROLE CONTRACT
PRODUCT SOURCE: Images 1-4. Use only these sources for the final garment.
LINE_ART SOURCE: approved black-and-white line-art. Use only for pose, crop, body scale, hands, legs, and composition.
MODEL APPEARANCE LOCK: [skin tone, hair color, hairstyle]. Use only this for model appearance.
ACCESSORY SOURCES: [image numbers]. Use only these listed accessories.
BOTTOMS SOURCE: [image number or omit]. Use only this listed bottom.

REFERENCE PRIORITY
Garment identity must match PRODUCT SOURCE first.
Pose and crop must match LINE_ART SOURCE first.
Skin tone and hair must match MODEL APPEARANCE LOCK first.

GARMENT HARD LOCK
[exact product details]

POSE AND BODY HARD LOCK
[exact pose, crop, hand, leg, body scale locks]

DO NOT INCLUDE
No text, watermarks, random styling, unlisted accessories, changed pose, changed crop, changed skin tone, changed garment design, borrowed benchmark outfit details, or borrowed line-art outfit details.

八、验收检查

输出前检查

是否完成线稿策略、线稿 Prompt、可用线稿确认、产品拆解、最终策略确认。

最终图检查

是否为 3:4、4K、纯白背景；是否只有一个模特；是否产品不改款、动作不漂移、肤色不随机。

防混图检查

是否明确禁止对标图原服装、线稿残留服装设计、人台、文字水印、额外配饰、额外鞋包。
