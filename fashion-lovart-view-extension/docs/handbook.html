03 / INPUT CONTRACT

输入不是编号，是视觉证据

Skill 接受单个 SKC 或批次根目录。图片保留原名称与位置，系统通过实际画面判断语义角色；数字文件名不会被当成角色规则。

model_source

模特身份、人体和基础穿搭参考

product_source

颜色、版型、领口、袖型、长度与面料证据

scene_source

背景环境、光向、色温与投影依据

accessory_source

06 / CANVAS PLACEMENT

每做好一张，就马上排列一张

画布不是最终收尾工作，而是每个任务完成时的即时事务。点击视角标签，查看主槽与补图带的归属关系。

左：5 个主槽 · 右：同视角补图带
01 · 结果完成暂停补位提交
02 · 放入主槽按视角与动作定位
03 · 视觉确认尺寸、间距、保存状态
04 · 再补队列填充释放的并发位
07 / QUALITY GATE

生成只是候选，核验通过才算完成

20 张基础图生成完后进行统一质检。轻微自然变化可接受，但产品设计、动作核心、视角目的与全身边界不可改变。

产品一致性
  • 颜色、版型、领口、袖型、长度和面料正确
  • 视角与动作合同一致
  • 包袋、鞋子和手部正确
图像真实性
  • 单图、单个成年模特、无拼图
  • 光向、投影、反射与色温统一
  • 无抠图白边、严重肢体错误、文字或水印
四视角不得混淆

正面、侧面、背面、全身分别服务于不同展示目的，不能仅凭动作名称代替真实视角核验。

全身图专属边界

从头发最高点到两只脚底连续完整入镜，完整脸部、两只鞋、脚趾与鞋底可见，头顶和脚下均留安全边距。

ATTEMPT 1基础候选
ATTEMPT 2原提示词 + 精准纠错
ATTEMPT 3最后一次；仍失败则 blocked:quality
08 / RESUME

任何中断，都从 run-state 继续

每次可观察状态变化和每次画布移动都会落盘。重新运行时先查 Lovart 中已有标签，避免重复提交。

qualified

直接跳过，不重新生成

submitted / queued

先在月度项目中查找可见任务标签

rejected

未到 3 次上限时，继续带证据纠错

blocked

只隔离当前动作、视角或 SKC；批次继续

canvas_placement

记录行号、主槽/补图位和视觉确认结果

09 / RUN

入口会自动判断路径是单个 SKC 还是批次根目录。切换下方标签，复制对应调用方式。

11 / DEFINITION OF DONE

完成标准是一组同时成立的条件
