# Quality Checklist

用这份清单判断一次 `fashion-nano-tryon` 输出是否合格。

## 流程完整性

- 是否先做了参考图角色映射。
- 是否先确认黑白线稿策略和人物外观锁定。
- 是否等待用户生成或上传批准线稿。
- 是否只从产品图拆解主商品。
- 是否先确认最终合成策略，再输出最终 Nano Banana Pro prompt。

## 主商品一致性

- 主商品是否只来自 `PRODUCT SOURCE`。
- 产品颜色、花型、领口、袖型、腰部、下摆、面料和工艺是否完整。
- 是否禁止对标图原服装覆盖产品图。
- 是否禁止线稿原服装覆盖产品图。
- 是否没有使用人台比例改变模特身体。

## 动作与人体一致性

- 姿势、拍摄距离、裁切、主体比例是否来自 `LINE_ART SOURCE`。
- 肩宽、躯干长度、腰线、胯高、手臂长度、手掌大小是否锁定。
- 手位和腿位是否没有被配饰或产品参考图改写。
- 最终 prompt 是否明确不要改变 pose 和 crop。

## 外观与搭配一致性

- 肤色和发型是否来自 `MODEL APPEARANCE LOCK`。
- 可见皮肤颜色是否要求一致。
- 配饰和下装是否只来自明确提供的图。
- 配饰是否没有遮挡领口、肩部、腰部、面料纹理和下摆。

## Nano Banana Pro 输出一致性

- 最终 prompt 是否使用短块结构。
- 是否写明 `3:4 ratio, 4K output`。
- 是否写明纯白背景 `#FFFFFF`。
- 是否只生成一张高端电商棚拍图。
- 是否排除文字、水印、logo、随机符号、多人物、拼图和背景道具。
