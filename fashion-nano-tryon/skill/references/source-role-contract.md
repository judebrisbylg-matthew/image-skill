# Source Role Contract

`fashion-nano-tryon` 的核心不是把多张图当成 moodboard 混合，而是把每张图分配到固定控制角色。角色一旦确认，后续 prompt 必须持续遵守。

## 标准输入角色

| 角色 | 常见来源 | 只允许控制 |
| --- | --- | --- |
| `PRODUCT SOURCE` | 产品图，多角度人台、平铺或细节图 | 最终主商品的款式、颜色、结构、比例、面料、纹理、工艺、五金、长度和体量 |
| `BENCHMARK SOURCE` | 对标模特图 | 生成线稿前的人物外观锁定，以及线稿所需的姿势、构图、裁切和空间关系 |
| `LINE_ART SOURCE` | 已批准的黑白线稿 | 姿势、拍摄距离、裁切、身体比例、手位、腿位、主体比例、服装与身体空间关系 |
| `MODEL APPEARANCE LOCK` | 从对标图提取的文字描述 | 肤色、可见皮肤一致性、发色、发型、基础模特外观 |
| `ACCESSORY SOURCES` | 配饰图、包、腰带、首饰、帽子、眼镜等 | 已明确提供的配饰类别、数量、颜色、材质、形状、尺寸关系和佩戴位置 |
| `BOTTOMS SOURCE` | 牛仔裤、裤子、裙子、短裤等 | 下装的类别、颜色、版型、腰头、口袋、裤型、洗水和可见细节 |
| `DENIED SOURCES` | 未授权信息 | 对标图原服装、线稿原服装、人台比例、随机配饰、随机肤色、文字、logo、水印和背景 |

## 角色优先级

1. 主商品永远以 `PRODUCT SOURCE` 为最高优先级。
2. 动作、构图、手位和人体比例以 `LINE_ART SOURCE` 为最高优先级。
3. 肤色和头发以 `MODEL APPEARANCE LOCK` 为最高优先级。
4. 配饰和下装只来自明确标注的 `ACCESSORY SOURCES` 与 `BOTTOMS SOURCE`。
5. 任何来源冲突时，先保商品身份，再保线稿动作，最后决定配饰是否可见。

## 新人判断规则

- 产品图里没有的主商品结构，不要从对标图补。
- 对标图里的衣服即使好看，也只用于线稿阶段的空间关系。
- 线稿没有颜色，所以最终肤色不能从线稿推断。
- 配饰图只提供配饰本身，不允许改变主商品领口、袖型、下摆或廓形。
- 如果手位或裁切不支持完整显示某个配饰，允许只显示可见部分，不允许改动作硬塞配饰。
