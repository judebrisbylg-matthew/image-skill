# Workflow Gates

这个 skill 必须保留线稿辅助流程。不能因为用户说“执行”就直接输出最终白底图 prompt。

## 阶段总览

| 阶段 | 输出 | 等待确认 |
| --- | --- | --- |
| Stage 0 | 参考图角色映射 | 角色有歧义时必须确认 |
| Stage 1 | 黑白线稿生成策略 + 人物外观锁定 | 必须确认 |
| Stage 2 | 黑白线稿 Prompt | 等用户生成或上传批准线稿 |
| Stage 3 | 产品特征拆解 | 必须确认 |
| Stage 4 | 最终白底展示图生成策略 | 必须确认 |
| Stage 5 | Nano Banana Pro 最终英文 Prompt | 最终交付 |

## Gate 1: 线稿策略确认

在用户确认黑白线稿策略前，不输出线稿 prompt。

需要确认的信息：

- 对标图控制什么。
- 线稿保留哪些姿势、比例、手位、腿位、裁切和空间关系。
- 哪些颜色、图案、品牌、材质和背景必须弱化。
- 人物外观锁定是否准确。

## Gate 2: 线稿结果确认

在用户确认线稿可用或上传批准线稿前，不进入产品拆解和最终策略。

线稿可用标准：

- 黑白线稿干净。
- 保留对标图拍摄距离和裁切。
- 保留关键手位、腿位、身体角度和比例。
- 没有彩色、灰底、随机文字、品牌标识或复杂材质表现。
- 原服装只剩空间线索，不是详细设计稿。

## Gate 3: 产品拆解与最终策略确认

在用户确认产品拆解和最终白底展示策略前，不输出 Nano Banana Pro 最终 prompt。

需要确认的信息：

- 主商品身份是否准确。
- 产品结构、长度、体量、面料和工艺是否完整。
- 配饰和下装来源是否清晰。
- 线稿动作与产品结构如何保守融合。
- Nano Banana Pro 防混图规则是否明确。

## 自动批处理例外

当 `fashion-lovart-nano-batch` 调用本 skill 时，可以进入自动批处理模式。自动批处理模式默认各阶段已确认，但仍必须产出同样的线稿 prompt、外观锁、产品拆解、最终策略和 Nano Banana Pro prompt。
